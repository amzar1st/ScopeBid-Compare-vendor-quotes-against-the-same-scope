## Description

ScopeBid helps buyers compare vendor quotes against the same versioned request for quotes. Vendors sign their submissions with a Studio account. After the buyer closes the RFQ, GenLayer validators independently classify each requirement as included, excluded, conditional, or missing. Consensus requires matching outcomes and quote-line citations. The dashboard reads finalized results and shows price and scope side by side. In the fictional solar demo, the $9,850 quote excludes utility interconnection paperwork, while the $10,900 quote includes it and makes commissioning conditional on utility approval. Scope, quote text, and review commitments make the comparison reproducible.
